# Guide d'Utilisation CoopLedger

Bienvenue dans l'écosystème **CoopLedger**, votre plateforme de gouvernance et de gestion de trésorerie pour coopératives agricoles.

##  Présentation du Concept
CoopLedger est une solution hybride (Web + Mobile) permettant une gestion transparente et sécurisée des fonds et des décisions d'une coopérative. Toutes les transactions et tous les votes sont enregistrés sur un registre numérique immuable (Ledger) pour garantir une confiance totale entre les membres.

---

## Le Tableau de Bord Web (Administration & Suivi)
Le site web est l'outil principal pour les administrateurs (Président, Trésorier) et pour la consultation globale.

### 1. Navigation
Le menu latéral vous permet de naviguer entre :
- **Tableau de Bord** : Vue d'ensemble des finances et des statistiques.
- **Propositions** : Liste des votes en cours et passés.
- **Analytiques** : Graphiques d'évolution du capital.
- **Gouvernance** : Paramètres de la coopérative.

### 2. Gestion des Propositions
Pour créer une nouvelle dépense ou un projet :
1. Allez dans **Propositions** > **Nouvelle Proposition**.
2. Remplissez le formulaire (Titre, Montant, Description).
3. Une fois soumise, la proposition apparaît instantanément sur les téléphones mobiles de tous les membres pour le vote.

---

##  L'Application Mobile (Vote & Notifications)
L'application mobile est conçue pour l'interaction quotidienne des membres, même sur le terrain.

### 1. Authentification
Connectez-vous avec vos identifiants fournis par la coopérative. Votre rôle (Président, Membre, etc.) détermine vos permissions.

### 2. Voter pour une Décision
- Dès qu'une proposition est créée sur le Web, elle s'affiche dans l'onglet **Votes**.
- Vous pouvez voter **POUR** ou **CONTRE**.
- Les résultats sont mis à jour en temps réel sur le tableau de bord web.

### 3. Suivi de Trésorerie
L'onglet **Ledger** (Transactions) vous permet de voir chaque mouvement d'argent. Chaque transaction est certifiée numériquement, empêchant toute falsification.

---

##  Interaction Web-Mobile : Comment ça marche ?
1. **Initialisation** : Le Trésorier crée une proposition de dépense sur le **Dashboard Web**.
2. **Consultation** : Les membres reçoivent une notification et voient la proposition sur leur **App Mobile**.
3. **Action** : Les membres votent via leur mobile.
4. **Validation** : Une fois le temps écoulé ou le quorum atteint, le statut de la proposition change automatiquement (Approuvée/Rejetée).
5. **Exécution** : Si approuvée, la transaction est enregistrée et le solde est mis à jour sur les deux plateformes.
